# companion-module-showsign-signage

Bitfocus Companion module for [ShowSign](https://portal.showsign.io) — fire on-screen
announcement cues to groups of displays (take-your-seats prompts, "starting now" flashes,
looping brand clips) from a Stream Deck or any Companion surface.

See [companion/HELP.md](./companion/HELP.md) for setup and usage.

## Development

```bash
yarn install
yarn format     # prettier
yarn package    # builds a .tgz you can import into Companion
```
